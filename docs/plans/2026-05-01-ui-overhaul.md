# UI Overhaul: Structural Redesign

## Goal

Replace the flat, table-driven popup layout with a zone-based structure using progressive disclosure. Make the tool feel approachable to casual users while keeping power features accessible.

## Design Brief (confirmed)

- **Register:** Product
- **Color strategy:** Restrained (warm neutrals + single accent)
- **Anchors:** Airbnb (dense but beautiful), Arc browser sidebar (compact disclosure)
- **Scope:** Entire popup.html, production-ready
- **Library:** Own panel (tab/toggle), not inline
- **Parser options:** Keep conditional, move to grouped settings
- **Viewport:** Desktop-only, no mobile concern

## Constraints: JS-DOM Dependencies

The following tables are **dynamically generated by JavaScript** and MUST remain as `<table>/<tr>/<td>`:

| Table | File | Why |
|-------|------|-----|
| `#chapterUrlsTable` | ChapterUrlsUI.js | Creates `<tr>/<td>` dynamically, queries `querySelectorAll("tr")`, uses `nth-of-type(3)` |
| `#imagesTable` | CoverImageUI.js | Creates `<tr>/<td>` for image rows |
| `#readingListTable` | ReadingList.js | Creates `<tr>/<td>`, uses `parentElement.parentElement` |
| Filter table (sidebar) | ChapterUrlsUI.js | Generates entire `<table>` in `generateFiltersTable()` |
| Library HTML | Library.js | Generates table HTML via innerHTML strings |

**Safe to restructure** (only queried by ID):
- `#inputTable` (input form)
- `#AdditionalMetadatatable` (metadata options)
- `#advancedOptionsTable` (advanced options)
- `#rangeSelectTable` (chapter range selects)

**i18n fix required:** `main.js:422` queries `"td, th"` for localization. Labels moved out of tables need the `.i18n` class (already in the selector list).

## Architecture: Five Zones

### Zone 1: Source
The URL input + Load button. Extracted from `#inputTable` into its own prominent container. This is the entry point.

### Zone 2: Book Identity
Title, Author, Language, Filename fields in a compact form grid (CSS Grid, not table). Cover image floats right. Parser-specific checkboxes (remove author notes, translation, etc.) appear conditionally below.

### Zone 3: Action Bar
Pack EPUB button (primary), progress bar, Library toggle, Add to Library. Visually distinct band.

### Zone 4: Chapter Workspace
Range selects, volume mapping, chapter table, pagination. The `#chapterUrlsTable` STAYS as a table. Wrapper structure uses flex layout.

### Zone 5: Settings
Replace flat `#advancedOptionsSection` with grouped `<details>/<summary>` sections:

**Group: Output**
- Custom filename + help
- Use full title as filename
- Overwrite when duplicate
- Max chapters per EPUB
- Create EPUB 3
- Add information page
- No download popup

**Group: Images**
- Skip images
- Include image source URL
- Highest resolution images
- Compress images (+ resolution, format, JPG cover sub-options)
- Use SVG for images
- Remove duplicate images
- Cover from URL

**Group: Metadata**
- Metadata URL + load button
- No additional metadata
- Auto-search metadata
- Less tags
- Subject textarea
- Description textarea
- Series name + volume
- Show more metadata options

**Group: Content**
- Stylesheet textarea + reset button
- Remove next/previous chapter hyperlinks
- Un-superscript alternate translations
- Chapters page in chapter list
- Skip chapters that fail fetch
- Send to Kindle
- File author as

**Group: Behavior**
- Manual delay per chapter
- Override default minimum delay
- Include in reading list + view button
- Disable shift-click alert
- Disable image resolution error
- Disable webp image format error

**Group: Appearance**
- Theme selector
- Advanced options visible by default
- Manually select parser

**Group: Developer**
- Diagnostics checkbox + reload button
- Write options to file
- Read options from file
- Write error history to file
- Reset button

### Library Panel
`#hiddenBibSection` becomes a toggleable panel with its own dedicated button. When open, it pushes content down (not a sidebar). Internal structure unchanged (Library.js generates its own HTML).

## Risk Mitigation

1. **Keep all IDs** unchanged to preserve JS functionality
2. **Keep dynamic tables** as tables (chapter list, images, library, reading list, filters)
3. **Test i18n** after restructuring: verify all `__MSG_` labels still get localized
4. **Test parser-specific rows**: verify conditional show/hide still works after moving to settings groups
5. **Test Library toggle**: verify Library.js can still render into its container

## Implementation Notes

The following deviations from the original plan were made during implementation:

1. **Image options not moved** -- `duplicateImagesRow` and `coverFromUrlRow` remain in `#imageSection` instead of moving to Settings > Images. Reason: `CoverImageUI.showCoverImageUrlInput()` toggles `#imageSection` visibility dynamically; moving options would require JS changes.
2. **"Send to Kindle" in Output group** instead of Content. Output is a better fit since it relates to post-EPUB-creation behavior.
3. **"File Author as" in Metadata group** instead of Content. Metadata is a better fit since it is a metadata field.
4. **"Show more metadata options" as standalone toggle** above all settings groups, not inside Metadata. Controls visibility of the entire `AdditionalMetadatatable` div.
5. **"Translator" and "File Author as" moved into Metadata details group** from old advancedOptionsTable position. Logical improvement since they are metadata fields.
